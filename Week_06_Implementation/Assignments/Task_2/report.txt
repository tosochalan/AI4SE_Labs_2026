The chunker uses Python's AST to keep classes and functions intact where practical, with a 100-line target for Python chunks. An oversized class is divided between complete members (such as methods), and a method or function that is still too large is split at complete top-level body statements. The class or function header and docstring are repeated in each part to preserve context. A single statement larger than the limit remains intact rather than being cut into a potentially misleading fragment. Module-level code and non-Python text files remain chunks. `structure.json` records each chunk's ID, relative path, kind, name, line range, and text for later retrieval.
